# 📚 Book CRUD Application

A full-stack Book Management Application built with React, Node.js, Express.js, and MongoDB.

## 🚀 Features

- Add a new book
- View all books
- Update book details
- Delete a book
- REST API
- MongoDB Database

## 🛠️ Tech Stack

### Frontend
- React
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## 📂 Project Structure

```
client/
server/
```

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/book-crud-app.git
```

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```

## 🌐 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/auth/book | Create Book |
| GET | /api/auth/booklist | Get All Books |
| PUT | /api/auth/update/:id | Update Book |
| DELETE | /api/auth/delete/:id | Delete Book |
